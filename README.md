# Mnemo
Mnemo é um Modelo de Machine Learning desenvolvido para Fins Educacionais, que age através de uma aplicação web feita em Fast API de mesmo nome, a qual o Modelo alimentado por whisper transcreve audios que de preferência sejam aulas, em flashcards e cria simulados estilo ENEM, projeto pessoal OpenSource desenvolvido a fim de Auxilio de Estudo.s.,
